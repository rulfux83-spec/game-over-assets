# Game Over App · pack de imágenes

Recursos opcionales que Game Over App descarga desde **Telemetría › Pack de imágenes**.
La versión de la Microsoft Store no los lleva dentro.

| Carpeta | Contenido | Se instala en |
|---|---|---|
| `logos_coches/` | Logos de las marcas de coches (PNG) | `assets/logos` |
| `banderas/` | Banderas de países (PNG) | `pack_imagenes/banderas` |
| `mapas/` | Planos de los circuitos por TrackID (JSON: `[pct, x, y]`) | `assets/track_maps` |
| `mapas_png/` | Imagen de cada circuito (PNG) | `assets/track_maps_png` |
| `carteles_sesiones/` | Carteles de sesiones | `pack_imagenes/carteles_sesiones` |

Las marcas y los logos pertenecen a sus propietarios. Aquí solo se usan para identificar el coche de cada piloto.
Game Over App es un programa independiente y no está afiliado a iRacing.com Motorsport Simulations, LLC, a Reiza
Studios ni a ningún fabricante.
